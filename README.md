# kakuyomu-dl

A downloader to fetch novel chapters from [kakuyomu](https://kakuyomu.jp/) and write into epub files.

## Usage

```bash
git clone https://github.com/aotorii/kakuyomu-dl.git
```

```bash
cd kakuyomu-dl
```

```bash
pip install -r requirements.txt
```

```bash
python src/main.py -h
```
